The release executable is a native x64 Windows PE application compiled from the
C source in the src folder. It relies only on Windows system DLLs and built-in
Windows PowerShell networking commands.

Release target:
    x86_64-windows-gnu

Subsystem:
    Windows GUI

Linked Windows libraries:
    iphlpapi
    ws2_32
    comctl32
    shell32
    ole32
    advapi32
    gdi32
    uxtheme
    dwmapi

Build from source on Windows:
    Open a Visual Studio 2022 Developer Command Prompt and run BUILD-WINDOWS.bat.

Cross-build command used for the release:
    x86_64-w64-mingw32-windres app.rc -O coff -o app-resource.o
    x86_64-w64-mingw32-gcc -std=c11 -O2 -Wall -Wextra -Wpedantic -mwindows
    src/main.c src/config.c src/validation.c src/shell_tools.c src/ui_layout.c src/diagnostics.c
    app-resource.o -o NICEquipmentManager.exe -liphlpapi -lws2_32 -lcomctl32 -lshell32
    -lole32 -ladvapi32 -lgdi32 -luxtheme -ldwmapi

The program validates every address, prefix, and port before constructing any
network command. PowerShell commands identify adapters by numeric interface
index rather than accepting a user-entered adapter name.
